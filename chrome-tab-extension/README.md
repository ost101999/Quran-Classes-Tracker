# إضافة استدعاء تبويب الحصة

تتيح هذه الإضافة للتطبيق البحث عن رابط الحصة المفتوح في Chrome وإظهار تبويبه بعد نسخ التقرير. تتطلب صلاحية قراءة عناوين التبويبات، وتتواصل مع تطبيق سطح المكتب محليًا على الجهاز فقط.

1. افتح `chrome://extensions` في Chrome، وفعّل «وضع المطوّر».
2. اختر «تحميل إضافة غير مُجمّعة» (Load unpacked)، واختر المجلد الذي يحتوي على هذا الملف و`manifest.json`.
3. أعد تشغيل تطبيق Quran Classes Tracker، وتأكد أن إضافة Chrome مفعّلة.

في نسخة التطبيق المثبتة يوجد المجلد داخل `resources/chrome-tab-extension` في مجلد تثبيت التطبيق. في نسخة المشروع، استخدم مجلد `chrome-tab-extension` مباشرةً.

عند تعطيل الإضافة أو عدم تشغيل Chrome يفتح التطبيق الرابط بالطريقة المعتادة. لا يمكن للإضافة الوصول إلى نوافذ التصفح المتخفي إلا إذا سُمح لها بذلك من إعداداتها في Chrome.
